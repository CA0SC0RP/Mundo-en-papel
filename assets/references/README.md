# Biblioteca visual — Mundo en Papel

Esta carpeta reúne imágenes de referencia, capturas y recursos aprobados del proyecto.

## Estado inicial

La imagen maestra histórica de Mountains That Breathe está enlazada desde el repositorio anterior y se muestra en `docs/REFERENCIAS_VISUALES.md`. No se ha copiado físicamente aquí.

## Organización prevista

- `approved/`: referencias aprobadas por el usuario; conservar originales.
- `historical/`: capturas y recursos de etapas anteriores.
- `ui/`: capturas de interfaz y referencias de flujo de trabajo.
- `characters/`: personajes, hojas de poses y sprites.
- `scenes/`: escenarios, fondos y composición.

No guardar aquí exportaciones temporales, duplicados ni recursos con licencia desconocida. Antes de incorporar una imagen, documentar origen, autor, fecha aproximada, propósito, estado y hash. No reemplazar un original por una versión editada.
